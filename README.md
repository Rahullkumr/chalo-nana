# touch-grass

My submission to DEV's [Hacktoberfest Open-Source AI Challenge: Week 1 — Touch Grass](https://dev.to/challenges/hacktoberfest-week1-2026-10-05), an open-source AI project that gets people off the screen and into the world.

## Prompt

**Build something with open-source AI at its core** that gets people off the screen and into the world.

- Core must be open tech: open-weight models, open-source agent harnesses or frameworks, local inference, or all three. The open pieces should be what makes the project work.
- Hiking, gardening, birding, run clubs, fall foliage: if it gets someone outside, it counts. The screen should be the shortest part of the experience.
- Show why open matters for the use case (works offline in the backcountry, keeps location data private, swappable or fine-tunable models, free to run).
- Bonus: take it outside, use it, and write about how it went.

## Submission

Publish a DEV post using the challenge template, tagged `devchallenge`, `hf26challenge`. Must be a new project built during the challenge window; one entry per person.

Template sections:
- What I Built
- Demo
- Code
- How I Built It
- Why Does Open Innovation Matter?
- My Agent Session (optional, DevRelay)
- Prize Categories

Teams: one member posts and credits teammates by DEV username.

## Judging

1. Writing Quality (weighted most heavily)
2. Relevance to the Prompt and Theme
3. Creativity
4. Technical Execution
5. Use of Partner Technology (optional, for prize categories)
